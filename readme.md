# 🩺 Multi-Disease Prediction System

An advanced clinical decision-support web application powered by **Machine Learning** and built using **Streamlit**. This platform allows users to assess potential health risks across multiple medical domains through an interactive, clean, and real-time interface.

---

## 🌟 Features

- **🏠 Home Overview:** Comprehensive dashboard introducing the system capabilities.
- **❤️ Heart Disease Prediction:** Assesses cardiovascular risks based on clinical attributes (Age, Blood Pressure, Cholesterol, etc.).
- **🎗️ Breast Cancer Classification:** Evaluates cell nuclei characteristic metrics (Radius, Texture, Perimeter, Area, etc.) to detect benign or malignant tumors.
- **🧠 Student Mental Health Evaluation:** Analyzes academic and lifestyle indicators (CGPA, Study Satisfaction, Financial Stress) to gauge depression or mental health risk.

---

## 🛠️ Tech Stack

- **Frontend & UI:** Streamlit
- **Machine Learning:** Scikit-Learn (Random Forest / Classifiers)
- **Data Processing:** Pandas, NumPy
- **Model Serialization:** Pickle (`.pkl`)
- **Environment:** Python, VS Code
